# DeepSeek API 接入验收

日期：2026-10-29。

## 实现

- 固定官方 HTTPS 地址和 `deepseek-flash` 模型名，按官网说明当前对应 DeepSeek-V4.1-Flash-1017。
- Rust reqwest + TLS 证书校验；不跟随重定向，避免把凭据发送到其他地址。
- Windows Credential Manager 保存 Key，只向前端返回是否已配置。
- SSE 按字节缓冲，支持 UTF-8 跨网络分块、CRLF、心跳注释、合并事件、结束原因和 `[DONE]`。
- 每条请求独立 ID；前端通过 Tauri Channel 接收增量，忽略过期事件。
- 停止请求会取消并丢弃进行中的网络 future；保留已显示的文字。
- 连接超时 15 秒、响应头等待 60 秒、流读取空闲 120 秒；不思考时整体生成 180 秒，开启思考时 600 秒。长时间无数据会明确报错。
- 无效 Key、余额不足、限流、服务异常、流提前终止分别提示；不把服务端原始错误正文或认证头写入日志。
- 当前使用按容量触发的滚动摘要，已取消最近 10 轮截断；独立 system 文件最多 64 KiB，输出上限随思考档位变化。实现见 [上下文与 memory](context-memory.md)。
- 深度思考默认关闭，可切换 low / high / max；无联网搜索、图像采集或工具执行。

## 自定义配置扩展

- API Key 继续通过设置界面独立配置，保存在 Windows 凭据管理器。
- `src-tauri/src/settings.rs` 管理配置：思考偏好保存在应用配置目录的 `assistant-settings.json`；仓库运行读取根目录 `system-prompt.txt`，独立 exe 回退到应用配置目录。UI 返回实际路径、字数、预览和读取错误，不返回 Key。
- 每次 `start_chat` 读取当前思考偏好与提示词文件，构成一次不可变的请求快照。默认文件仅在缺失时创建，不覆盖已有内容；文件变更下一条请求生效。
- 系统提示词使用独立 `role: system` 消息置于请求首位，随后是最近完整会话与当前 user 输入。留空省略 system 消息；文件不可读、非 UTF-8 或过大时阻止请求。
- UI 四档映射：不思考 → `thinking.type: disabled`，其余 → `thinking.type: enabled` + `reasoning_effort: low/high/max`。没有伪造 medium 档位。输出预算分别为 4096 / 8192 / 16384 / 32768 tokens（思考与正文共享）。
- `reasoning_content` 只触发一次「正在思考」状态，不存储原始思考文本；最终正文仍通过原有 Channel 增量传递。无正文但思考耗尽预算时显示可操作错误。
- 思考选择保存失败时 UI 保留旧值；保存或生成期间禁用切换，避免新请求使用未保存的选项。

## 验证证据

以下是 API 接入阶段的记录；当前聊天与存储扩展的测试记录见 [聊天体验验收](chat-experience.md)。

1. `cargo test`：9 项 Rust 离线测试通过，2 项真实 API 测试默认忽略。新增覆盖四档请求参数、system 顺序、思考事件、文件热读取/编码/大小/缺失、用户文件不被覆盖、启动路径和偏好持久化。
2. 显式运行 `live_deepseek_stream`：官网请求成功，收到 **28 个增量 / 51 个字符**，结束原因 `stop`。调用的是产品同一套 Rust 请求与 SSE 解析代码；报告不包含 Key 或完整回答。
3. 显式运行 `live_thinking_system_prompt`：官网低思考模式返回思考进度，并遵循固定系统指令输出预期结果，结束原因 `stop`。报告 `artifacts/local/thinking-system-test.json` 中三个校验字段均为 true；高/最高档位仅完成离线参数验证。
4. Playwright：10 项交互测试通过，包括逐段渲染、Markdown、连续追问上下文、停止请求早于原生确认的竞态、失败重试不重复问题、忽略旧请求事件、缺少 Key 不发送请求、禁用模型 HTML 与外部图片、思考切换/保存失败/流式状态，以及 Key 替换/删除、提示词打开/刷新。浏览器中的持久化使用模拟 IPC；真实文件持久化由 Rust 测试覆盖。
5. 原生桌面重新构建成功；GDI 捕获回归通过：未保护色块覆盖率 100%，保护后色块 0%、背景 100%；原生置顶、紧凑/展开、隐藏/恢复检查通过。
6. TypeScript / Vite 生产构建、Rust fmt、Clippy（所有 targets，warnings 视为错误）通过；源码与文档 Key 模式扫描无匹配。

前端测试使用模拟 IPC，真实 API 测试使用 Rust 与官网连接，二者的测试范围分开记录。没有在测试里把用户资料发给模型，仅发送固定测试问题与固定测试系统指令。

## 使用边界

滚动模型别名未来可能升级；不宣称固定快照永久不变。保存 Key 不等于 Key 有效；官网撤销后下一次请求会报错，可在设置里更换。

聊天体验扩展后，会话自动保存到本机 JSON 文件并在下次启动恢复；Key 仍保存在凭据管理器。对话期间隐藏窗口不会停止生成，点击「停止生成」才会取消请求。窗口捕获排除并非消息加密或对本机其他进程的访问隔离。
