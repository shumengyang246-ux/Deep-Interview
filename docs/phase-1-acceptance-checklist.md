# 第一阶段功能与验收清单

整理日期：2026-10-30。对应当前仓库 `0.1.0` Windows 桌面版本，已撤回捕获排除开关。本清单依据现有代码、最近测试记录与用户反馈整理，本轮未重新调用收费模型接口。

当前产品范围：支持自定义系统提示词、流式回答和会话内持久记忆的个人桌面 AI 助手。下列功能已实现；“用户验收”留空，不把实现完成或自动化测试通过视为用户已签收。

验收环境请记录：Windows 版本、显示缩放比例、显示器数量、WebView2 版本、会议软件及版本、共享整个屏幕/单个窗口、接收端设备。

## 7. 数据与容量边界

- 用户发起提问时，仅向固定 DeepSeek 官网接口发送系统提示词、当前会话所需上下文、当前问题，以及需要压缩的历史；没有云端历史列表同步。
- 聊天和摘要以本机普通 JSON 文本保存，未做聊天文件加密。API Key 单独保存于 Windows 凭据管理器。删除本机 Key 不会撤销官网 Key。
- 应用配置目录为 `%APPDATA%/com.deepinterview.assistant`，包含 `conversations.json`、`ui-settings.json`、`assistant-settings.json`；仓库运行使用根目录系统提示词，独立 exe 可使用应用配置目录中的提示词文件。
- 会话存档上限 25 MiB、500 个会话、单会话 10000 条消息；超过限制会报错，不自动删除旧会话。
- 上下文总工作预算为 128,000 **估算单位**，扣除系统提示词、输出预留与余量后，在剩余输入预算的 80% 触发整理；这不是精确 token 计数，也不是官网最大上下文声明。摘要上限 8000 UTF-8 字节。
- 四档输出预算依次为 4096 / 8192 / 16384 / 32768 tokens，思考和正文共享；摘要生成会额外调用 API。自动压缩是有损的，不能验收为“任何细节永远不会忘记”。

## 10. 当前未实现的范围

2026-10-30 增量：已加入输入框左下角的联网搜索开关、DeepSeek 官方搜索工具和来源展示；新的测试及验收项见 [联网检索说明](web-search.md)。上文原阶段测试数字保留为当时记录。

因此当前可以按“Windows 个人悬浮 AI 聊天助手”签收基础功能；若要求第一阶段覆盖“所有会议软件、所有共享模式均无助手、无黑块、无闪现”，需要补齐对应远端证据后再签收该项。
